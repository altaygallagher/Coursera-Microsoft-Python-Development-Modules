# Coursera Microsoft Python Development Modules

Bu repo, **Coursera** platformunda tamamladığım Python kurslarındaki projeleri içermektedir.  
Projeler, **Microsoft Python Development** kursundan alınmıştır.

Ayrıca, bu projeleri düzenlerken ve yönetirken **Microsoft** ekosisteminden (ör. GitHub, VS Code) yararlanılmıştır.



## 🚀 Nasıl Çalıştırılır?

1.İlgili proje klasörüne gidin:
   ```bash
  cd coursex-moduleY
   ```


2.Gerekli kütüphaneleri yükleyin:
  ```bash
  pip install -r requirements.txt
  ```


3.Projeyi çalıştırın:
  ```bash
  python project.py
  ```


## 🛠 Kullanılan Teknolojiler
- Python 3.x
- Gerekli kütüphaneler: `requirements.txt` dosyasında listelenmiştir.
